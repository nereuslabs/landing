# 🌊 Nereus Landing Website

Official modern, minimalist landing website for **Nereus 2.0** — the terminal-first AI programming mentor built in Rust.

[![Website](https://img.shields.io/badge/Website-nereuslabs.github.io%2Flanding-0b7285?style=flat-square&logo=github&logoColor=white)](https://nereuslabs.github.io/landing/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg?style=flat-square)](LICENSE)

## 🎨 Design Philosophy
* **Minimalist & Startup-Inspired**: Designed with extreme restraint, intentional typography (Plus Jakarta Sans & JetBrains Mono), and zero AI template clichés.
* **Deep Sea Theme**: Obsidian abyss palette (`#06090e`), subtle glass surface cards, and bioluminescent cyan accents (`#00f5d4`).
* **Interactive Terminal Widget**: Live browser simulation of the Ratatui TUI cockpit with real-time Socratic feedback.
* **Zero Build Dependencies**: Pure HTML5, CSS3, and vanilla JS. Instant load times, hosted on GitHub Pages.
