# Nereus Landing Website

Official landing website for Nereus 2.0 — the terminal-first AI programming mentor written in Rust.

- **Live URL**: https://nereuslabs.github.io/landing/
- **Design System**: Neo Brutalism (All-Sea Gamut, Brief v5)
- **Deployment**: GitHub Pages from `main` branch

## Local Preview

Open `index.html` in any browser:
```bash
open index.html
```

## Structure

```text
landing/
├── index.html                  # Single-page semantic markup (Sections 4.1 to 4.10)
├── DESIGN_NOTES.md             # Design rationale & repo feature verification table
├── assets/
│   ├── css/
│   │   └── neo-brutalism.css   # Authoritative Section 3 tokens, font bindings, zero-blur layout
│   ├── js/
│   │   └── main.js             # Data-driven roadmap and stepped terminal demo
│   ├── fonts/                  # Self-hosted Host Grotesk font files (OFL)
│   ├── logo.svg                # Pixel art lighthouse emblem
│   └── og-image.svg            # 1200x630 Open Graph card
└── LICENSE                     # MIT License
```
