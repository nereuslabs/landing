AI-тютор от дорожной карты к уверенным навыками

Nereus строит персонализированную дорожную карту обучения, задаёт практические упражнения и проверяет знания — всё через диалог с ИИ. Скоро доступен.

Что такое Nereus?

Представьте себе персонального репетитора, который:

🗺️

Строит дорожную карту

Разбирает ваши цели и уровень, создавая пошаговый план обучения от основ до продвинутых тем.

📚

Даёт материалы

На каждом шаге выдаёт консольный материал, практические задания и упражнения с RAG-подкреплением.

✅

Проверяет и повторяет

Экзаменатор оценивает ваши ответы. Слабые места автоматически попадаются в повторение.

Как это работает

Три агента, один цикл. LangGraph решает, что делать дальше.

2

3

Возможности

RAG

Retrieval-Augmented Learning

ChromaDB-хранилище с эмбеддингами подкрепляет материалы и задания актуальными источниками.

offline

Работает без сети

Stub-провайдеры позволяют запускать полный цикл без Ollama и без доступа в интернет — идеально для CI/CD и демо.

memory

Память сессии

Агрегация слабых мест, session_brief- преамбула, dump/load for persistent checkpoints.

langgraph

LangGraph оркестрация

Условный роутинг PASS/RETRY/END, human-in-the-loop через interrupt, checkpointer для resume.

Python 3.11+ LangGraph Ollama ChromaDB Chainlit Docker
