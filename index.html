The Antidote to AI Brain Rot

          

            When tools think on your behalf, your judgment atrophies. Nereus turns the AI into a sparring partner that tests, challenges, and sharpens your capabilities.
          

        


        

          

            
PILLAR 01

            
Active Recall over Autocomplete

            

              Autocomplete trains your fingers to accept suggestions. Nereus trains your mind to foresee edge cases. You write every line; Nereus only asks questions when your reasoning breaks down.
            

          


          

            
PILLAR 02

            
Sandboxed Compiler Verification

            

              No fuzzy LLM scoring. Every submission compiles against real borrow check invariants, static analyzers, and test harnesses inside an isolated sandbox before the examiner evaluates your mental model.
            

          


          

            
PILLAR 03

            
Persistent Weakness Graph

            

              Nereus keeps an objective SQLite trace of your cognitive blind spots. If you consistently struggle with asynchronous lifetimes or cache invalidation, future katas systematically attack those vulnerabilities.
            

          

        

      

    


    
    

      

        

          
The 4-Stage Sparring Automaton

          

            An algebraic finite state machine modeled in pure Rust. No open-ended chat loops, no unpredictable tangents.
          

        


        

          

            
STAGE 1

            
Diagnostic Gauntlet

            

              Probes syntax, memory boundaries, and error patterns through an adaptive quiz to uncover real gaps.
            

            

              Contract: WeaknessReport
            

          


          

            
STAGE 2

            
Milestone Coach

            

              Synthesizes your diagnosed gaps into an ordered tree of dependencies, prioritizing high-friction topics.
            

            

              Contract: PrioritizedRoadmap
            

          


          

            
STAGE 3

            
The Kata Chamber

            

              Delivers concise theory and assigns targeted challenges tackling specific language and systems subtleties.
            

            

              Contract: KataChallenge
            

          


          

            
STAGE 4

            
Socratic Inquisition

            

              Executes code against sandbox test assertions. Emits PASS to advance or RETRY with targeted counter-questions.
            

            

              Contract: AssessmentScore
            

          

        

      

    


    
    

      

        

          
Pure Systems Craftsmanship

          

            Written from scratch in Rust. Zero Python overhead, zero virtualenv baggage, zero token waste in offline mode.
          

        


        

          

            
< 5ms Startup

            
Single Static Binary

            

              No Python runtime, no PyTorch dependencies. A compiled Rust binary that launches instantaneously in your terminal with ~15MB RAM.
            

          


          

            
100% Offline

            
Deterministic Stub Engine

            

              Run offline katas on an airplane without spending API tokens. The built-in stub engine allows complete hermetic training and testing.
            

          


          

            
Algebraic Safety

            
Exhaustive Rust FSM

            

              States and transitions are encoded as explicit algebraic enums. Invalid states cannot compile, guaranteeing reliable sessions.
