Как это работает

Три агента — один цикл. LangGraph решает, что делать дальше.

1
Coach
Строит дорожную карту
2
Tutor
Материал и задание
3
Examiner
Оценка ответа
PASS — следующая тема RETRY — повторить тему

Возможности

Контекст из знаний

ChromaDB‑хранилище с эмбеддингами подкрепляет материалы и задания актуальными источниками.

Память сессии

Агрегация слабых мест и персистентные чекпоинты для продолжения обучения в любой момент.

LangGraph оркестрация

Условный роутинг PASS/RETRY/END с человеческим вводом на основе interrupt.

Готово к запуску

Разворачивается через Docker Compose с поддержкой Ollama и ChromaDB.

Python 3.11+ LangGraph Ollama ChromaDB Chainlit
