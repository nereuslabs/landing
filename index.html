Why Socratic mentorship matters

Most AI tools act like eager assistants that dump answers into your editor. You get instant code, but retain zero mental model. Nereus forces you to build the intuition.

Standard AI Chatbots

  • ✕ Instantly leaks the full code solution, creating an illusion of competence without neural retention.
  • ✕ Overly flattering tone that validates incorrect assumptions instead of demanding proof.
  • ✕ No isolated test harness; cannot verify if code actually compiles or passes edge cases.

The Nereus Method

  • ✓ Asks counter-questions targeting the exact compiler diagnostic or logic flaw you introduced.
  • ✓ Executes your code in a hermetic sandbox against hidden test assertions before rendering judgment.
  • ✓ Maintains an objective weakness report and adapts future katas to your diagnosed failure modes.

A deterministic learning lifecycle

Instead of an unpredictable conversational loop, Nereus coordinates four specialized agents as an algebraic finite state machine.

STAGE 01

Diagnostic Agent

Probes syntax, memory semantics, and error handling through an initial adaptive quiz.

Output: WeaknessReport
STAGE 02

Coach Agent

Synthesizes your goals, deadlines, and diagnostic weaknesses into a dependency-ordered roadmap.

Output: PrioritizedRoadmap
STAGE 03

Tutor Agent

Delivers concise theory and assigns hands-on coding challenges for the active roadmap milestone.

Output: KataChallenge
STAGE 04

Examiner Agent

Runs your solution against sandbox assertions. Issues PASS to advance or RETRY with Socratic clues.

Output: AssessmentScore

Engineered for speed and correctness

Written in idiomatic Rust with zero runtime dependencies. Built to live in your terminal.

< 5ms Cold Start

Single Static Binary

No Python runtime, no virtualenv conflicts, no PyTorch overhead. A single binary that launches instantaneously with ~15MB RAM.

100% Hermetic

Offline-First Stub Engine

Every agent, state machine transition, and evaluation harness runs locally with our deterministic stub client. Zero API costs for testing.

Algebraic FSM

Exhaustive State Transitions

States and transitions are encoded as strict Rust enums. Invalid states cannot be represented or compiled, eliminating desync bugs.
