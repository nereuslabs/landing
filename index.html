Возможности

RAG

Контекст из знаний

ChromaDB‑хранилище с эмбеддингами подкрепляет материалы и задания актуальными источниками.

memory

Память сессии

Агрегация слабых мест, session brief и персистентные чекпоинты.

langgraph

LangGraph оркестрация

Условный роутинг PASS/RETRY/END с human-in-the-loop через interrupt.

docker

Готово к запуску

Разворачивается через Docker Compose с Ollama и ChromaDB.

Python 3.11+ LangGraph Ollama ChromaDB Chainlit
